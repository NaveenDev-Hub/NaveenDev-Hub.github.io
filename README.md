## Run locally

Static site — no build step required.

```bash
cd NaveenDev-Hub.github.io
python3 -m http.server 8765
```

Open [http://localhost:8765](http://localhost:8765).

## Deploy

Hosted with [GitHub Pages](https://pages.github.com/) from the `main` branch.

1. Push or upload files to `main`
2. **Settings → Pages →** source: `main`, folder `/ (root)`
3. Site publishes at `https://<username>.github.io`
